# Yohan TV

تطبيق Android عربي بواجهة RTL لاكتشاف المحتوى والبحث عنه وفتح المشاهدة مباشرة من `ak.sv`، دون سيرفر خاص أو قاعدة بيانات. المفضلة تُحفظ محليًا على الجهاز.

## التشغيل

```bash
pnpm install
pnpm start
```

للمعاينة عبر Expo:

```bash
pnpm dev:metro
```

## بناء APK من GitHub

المشروع يحتوي على workflow في `.github/workflows/build-apk.yml`. بعد رفع الملفات إلى مستودع GitHub:

1. أنشئ مشروعًا فارغًا على [expo.dev](https://expo.dev) أو سجّل دخولك إلى حساب Expo.
2. أنشئ رمز وصول EAS عبر `eas token:create` من جهازك.
3. أضف الرمز في GitHub من Settings → Secrets and variables → Actions باسم `EXPO_TOKEN`.
4. شغّل workflow المسمى **Build Yohan TV APK** من تبويب Actions.
5. سيبني EAS ملف APK للتوزيع الداخلي، ويمكن تنزيل رابط البناء من سجل العملية.

## حدود مهمة

التطبيق لا يستضيف ملفات الفيديو، بل يجلب صفحات المصدر ويفتح رابط المشاهدة المتاح. لذلك قد تتغير النتائج أو الروابط إذا غيّر المصدر بنيته أو قيوده. يجب استخدام المحتوى وفق الحقوق والقوانين المحلية.
